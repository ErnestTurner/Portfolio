# Cloudflare Web Analytics disclosure — review draft

Status: review-only copy. This file is not linked from the website and does not enable or change analytics.

## Proposed visitor-facing copy

Trikzik Labs uses Cloudflare Web Analytics to understand which pages are visited and how the site performs. Cloudflare's browser beacon reports aggregate usage and performance measurements, including visits, page views, page-load timing, Core Web Vitals, and general dimensions such as country, site host and path, referring site, device type, browser, operating system, and navigation type.

Cloudflare states that Web Analytics does not use cookies or local storage to collect usage metrics, does not fingerprint individuals using IP addresses, user-agent strings, or other data for analytics display, and does not track individual visitors across its customers' sites.

No account is required to use Trikzik Labs. This disclosure describes the existing Cloudflare Web Analytics service only; the site's separate custom-analytics prototype remains disabled and unpublished.

## Owner review notes

- This is plain-language product disclosure, not legal advice or a guarantee about every request Cloudflare processes to provide hosting, security, or analytics.
- Before publishing, confirm the desired contact method, applicable jurisdiction, retention language, lawful basis or consent requirements, and whether Cloudflare's account configuration has changed.
- Do not claim that Cloudflare never receives an IP address. The narrower documented claim is that Web Analytics does not fingerprint individuals via IP address, user-agent string, or other data for analytics display.
