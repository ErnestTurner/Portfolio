# Portfolio

**Status:** Public portfolio / publishing surface

Ernest's developer portfolio and browser-game showcase.

## Current direction

- Moon Snail becomes the featured playable game
- Starfall remains preserved as an earlier finished experiment
- Living Town, Gravity Lab, Outpost, and other active projects should be represented honestly by maturity
- Keep the site lightweight, responsive, and directly useful as portfolio evidence

## Project rule

GitHub is the source of truth for code and version history. Google Drive stores design documents, screenshots, recordings, builds, and other project assets.
